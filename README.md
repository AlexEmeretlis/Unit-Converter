# Metric / Imperial Unit Converter

A simple and interactive unit converter that allows users to convert between metric and imperial measurements for **length**, **volume**, and **mass**. This project was built as part of my JavaScript learning journey.

---

## 🚀 Live Demo
https://unit-converter-alex.netlify.app/

---


## ✨ Features

- Convert **meters ↔ feet**
- Convert **liters ↔ gallons**
- Convert **kilograms ↔ pounds**

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (DOM manipulation)**
